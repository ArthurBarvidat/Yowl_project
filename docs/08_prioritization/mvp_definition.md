# MVP Definition — Next Level

## MVP Objective
The MVP of **Next Level** aims to showcase the core concept of the app:  
a social network for gamers that allows users to share content, interact with the community, and find teammates based on game and skill level.

---

## 1. Main User Flow
The user logs into the app, browses the feed, creates a post (image or clip), interacts with content (likes and comments), and then searches for teammates by selecting a game and, if necessary, a rank.

This flow represents the central value of Next Level and must be fully functional in the MVP.

---

## 2. Essential Screens
The MVP includes the following screens:

- Login page  
- Home page with feed  
- Game search page  
- Teammate search page (game + rank)  
- User profile page  

---

## 3. Minimal Features
The following features must be operational in the MVP:

- User login  
- Feed display  
- Post creation with:
  - an image or  
  - a video clip up to 2 minutes long  
- Ability to like and comment on posts  
- Content search by game  
- Teammate search by game and rank  
- User profile display (bio, profile picture, posts)  
- Advanced moderation system  

---

## 4. Features Excluded from the MVP
To ensure a realistic development scope, the following features are not included in the MVP:

- One-to-one private chat  
- Notifications  
- Content recommendation algorithm  

---

## Conclusion
This MVP focuses on the essential features needed to validate the core idea of Next Level.  
More complex features are intentionally excluded to ensure a first version that is stable and coherent.
