# Prioritization Matrix — MVP Scope

We used the **MoSCoW prioritization method** to define the scope of the MVP.  
This method allows us to focus on the essential features needed to validate our project.

---

## Must Have
These features are essential for the proper functioning of the application.

- User authentication  
- Viewing a posts feed  
- Creating a post (image or video clip with a maximum duration of 2 minutes)  
- Liking and commenting on posts  
- Searching content by game  
- Searching for teammates by game and rank  

---

## Should Have
Important features that improve the user experience but are not critical.

- Subscriptions page (viewing posts only from followed players)  
- Profile page (biography, profile picture, user posts)  

---

## Could Have
Features that add value but are not essential to validating the core concept.

- Reporting and moderation system in chats  
- Editing or deleting a post  
- Advanced search  

---

## Won’t Have (for MVP)
Features intentionally excluded from the MVP in order to keep the development scope manageable.

- One-to-one private chat  
- Content recommendation algorithm  

---

## Conclusion
More advanced features are intentionally excluded to ensure a feasible development process and a stable first version of the application.
