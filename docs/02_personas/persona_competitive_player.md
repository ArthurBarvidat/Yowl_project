# Personas

This document contains various user profiles based on different needs.
Each profile represents a typical user of the social network dedicated to video games and helps guide design and functionality decisions.

## Personas type Competitive player

### Profile

- Age: 21
- Status: Student
- Platforms: PC
- Main Games: Valorant, League of Legends
- Skill Level/Rank: Diamond

### Goals

- Find teammates of a similar skill level
- Learn new game strategies
- Improve performance and climb the ranks

### Motivations

- Win games
- Play with serious and motivated players
- Be recognized for my skill

### Behaviors

- Uses Discord to find teammates
- Checks rank before playing with someone
- Plays several times a week, mainly in the evening

### Weaknesses

- Plays with random teammates of widely varying skill levels
- Wastes time searching on Discord
- Lack of an easy way to filter players by rank and role

## Personas de joueurs compétitifs

### Profil

- Âge : 21 ans
- Statut : Étudiant
- Plateformes : PC
- Jeux principaux : Valorant, League of Legends
- Niveau/Rang : Diamant

### Objectifs

- Trouver des coéquipiers de niveau similaire
- Apprendre de nouvelles stratégies de jeu
- Améliorer ses performances et progresser dans le classement

### Motivations

- Gagner des parties
- Jouer avec des joueurs sérieux et motivés
- Être reconnu pour mon talent

### Comportements

- Utilise Discord pour trouver des coéquipiers
- Vérifie son rang avant de jouer avec quelqu'un
- Joue plusieurs fois par semaine, principalement le soir

### Faiblesses

- Joue avec des coéquipiers aléatoires de niveaux très différents
- Perd du temps à chercher sur Discord
- Absence de moyen simple de filtrer les joueurs par rang et rôle
